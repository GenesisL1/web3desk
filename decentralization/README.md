# GenesisL1 decentralization evidence

This is the public, reproducible evidence layer for GenesisL1 consensus-decentralization claims.

The `latest/` directory contains the newest height-pinned snapshot. Historical observations are retained under `snapshots/`. Every report includes the exact raw JSON responses, ranked CSV, complete metrics, and SHA-256 checksums.

## Latest results

The first automated snapshot is generated by GitHub Actions after this evidence framework is published. Open [`latest/README.md`](latest/README.md) for the exact pinned height, validator count, concentration ratios, one-third coefficient, **two-thirds coefficient**, HHI, effective validator count, Gini coefficient, normalized entropy and ranked set.

## Reproduce locally

```bash
git clone --branch decentralization-evidence https://github.com/GenesisL1/web3desk.git
cd web3desk
python decentralization/scripts/capture_validator_snapshot.py
cd decentralization/latest
sha256sum -c SHA256SUMS.txt
```

No Python packages are required.

## Interpretation

CometBFT commits a block with **more than two-thirds** of active voting power. The one-third coefficient is primarily liveness-relevant: a coordinated cohort at or above one-third can prevent the remainder from exceeding two-thirds. It cannot alone finalize arbitrary state. The two-thirds coefficient measures the smallest leading cohort whose cumulative power is strictly above the commit threshold.

The repository makes the numbers reproducible. It does not infer shared ownership or infrastructure from validator names.
